This is a simple shooting game, I made it from python to update my logical mind and tbh it is really fun to make games by yourself rather then doing the vibe coding.

# How to install and use this game

The main requirement is you must have Python installed in your system.

1) Clone this repo

```bash
git clone <repo-link>
```

2) Install pygame 

```bash
pip install pygame
```

3) Execute the `main.py` file

```bash
python ./main.py
```

# How to play this game?

This is pc game, this just need one thing to play that is your mouse, it's a simple shooting game so just aim at the target and click to shoot, you will get the timer on, try to shoot as many zombie you want for making a new high score.
